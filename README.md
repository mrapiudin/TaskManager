# TaskManager

A modern minimalist To-Do List / Task Manager web application with a fresh and calming UI design.

## Features

- 🎨 **Modern Minimalist Design** - Clean, calming interface with custom color palette
- ✅ **Task Management** - Add, edit, delete, and complete tasks
- 📅 **Deadline Tracking** - Set and track task deadlines with visual indicators
- 🔍 **Smart Filtering** - Filter tasks by All, Today, or Completed status
- 📱 **Responsive Design** - Works perfectly on desktop and mobile devices
- 💾 **Local Storage** - Tasks are automatically saved to browser storage
- 🎯 **Intuitive UI** - Easy-to-use interface with hover effects and smooth animations

## Color Palette

- **Primary (Buttons)**: #3D8D7A
- **Secondary (Highlights)**: #B3D8A8  
- **Background**: #FBFFE4
- **Cards/Sections**: #A3D1C6

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start managing your tasks!

## Usage

### Adding Tasks
- Click the bold **"+ Add Task"** button
- Enter task title and deadline
- Click **"Save Task"** to add

### Managing Tasks
- **Complete**: Click the checkbox next to any task
- **Edit**: Click the ✏️ pencil icon to modify task details
- **Delete**: Click the 🗑️ trash icon to remove a task

### Filtering Tasks
- **All**: View all tasks
- **Today**: View only tasks due today
- **Completed**: View only completed tasks

## Technical Details

- **HTML5** - Semantic markup for accessibility
- **CSS3** - Modern styling with Flexbox, Grid, and CSS Variables
- **Vanilla JavaScript** - No frameworks, lightweight and fast
- **Responsive Design** - Mobile-first approach with media queries
- **Local Storage API** - Persistent data storage
- **Poppins Font** - Clean, modern typography
